# Pro Showdown play (web research, 2026-11-16) -> what the agent should learn

Sources are fan guides and community posts (mixed quality; no pro-team source found). Points that several sources agree on:

| Pro habit | What it means for the agent / sim |
|---|---|
| Lead shots: Piper's shots are narrow and slow over long range, so aim where the enemy will be, never auto-aim | Obs needs reliable enemy velocity; sim enemies must move and dodge like players; reward hits, not shots |
| Keep distance: Piper's damage grows with range; avoid assassins (Mortis, Edgar, Leon, Fang) | Distance-to-threat awareness; penalize close range as a marksman |
| Make other brawlers fight each other; join (third-party) a fight only when someone is low, without getting caught in the crossfire | Value finishing low-HP enemies (cube drops), not trading HP early |
| Cubes win endgames: farm boxes early and steal cubes by killing; don't die for one cube (killed brawlers drop theirs) | Cube reward with a death cost; cube count is a strong endgame stat |
| Gas: leave the gas zone early | Survival-first reward; storm/gas awareness |
| Check bushes before walking in (shoot them); watch the bushes around a box you're breaking | Bush memory + caution near boxes |
| At low HP, retreat to a bush and stop taking damage to regenerate | Learn the heal-by-disengage pattern |
| Wait for opponents to use their ammo, then engage; don't empty your own ammo | Ammo conservation (seen live: ammo waste) |
| Team modes: create 2v1s, focus one enemy, share cubes, keep roles (tank / damage / support) | Team obs + shared reward for teammate survival and team kills |
